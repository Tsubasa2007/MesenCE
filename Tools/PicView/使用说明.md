# PicView 使用说明

**PICVIEW.CMD** 是一个步步高 BBGDOS 程序（BBK 1.0），用来查看 122 号盘画图软件“神奇画笔”
（`BRUSH.EXC`）保存的图片：整幅画（`.Grp`，以及该盘上没有扩展名的 `BBG`、`BBK`、`YEAR`）和
剪贴图（`.Pct`）。它列出当前目录里的全部图片，一次显示一张，最下面一行显示文件名和“序号/总数”。
文件格式见 [../EasyMake/格式说明.md](../EasyMake/格式说明.md)。

| 操作 | 键盘 | 游戏杆 1 |
| --- | --- | --- |
| 下一张 | →、↓、PgDn、空格、回车、N | →、↓、A |
| 上一张 | ←、↑、PgUp、退格、P | ←、↑、B |
| 第一张 / 最后一张 | Home / End | |
| 退回 DOS | Esc、Q | Start |

装了鼠标驱动（MOUSE.CMD）以后游戏杆不能用：驱动接管了游戏杆扫描，BIOS 的游戏杆变量不再变化。
键盘始终可用。

## 使用方法

把 `PICVIEW.CMD` 复制到存有图片的盘上，在 `A:\>` 提示符下输入 `picview`（也可以在
`AUTOEXEC.BAT` 里加一行 `picview`）。需要先装入中文系统（`BBGCDOS`；122 号盘的
`AUTOEXEC.BAT` 已经执行 `bbgcdos/z4`）。按 Esc 退回 DOS。

`fat12add.py` 把文件复制到 FAT12 软盘映像的根目录，同名文件会被替换。它直接改写映像，请先复制一份：

    python fat12add.py "122 副本.img" PICVIEW.CMD

在 MesenCE 的 BBK 1.0 BIOS 上测试过（122 号盘全部 117 张图片，键盘和游戏杆，装与不装鼠标、
音乐驱动），在步步高 98 的 BIOS 上也能用。没有在真机上试过。

## 编译

仓库里已经有编译好的 `PICVIEW.CMD`。要重新编译需要 [cc65](https://cc65.github.io/)（`ca65` 和
`ld65`），放在 PATH 里，或者用 `CC65` 指定目录：

    CC65="/d/Program Files/cc65/bin" sh build.sh

技术细节（画图方法和用到的 BIOS 行为）见 [README.md](README.md)。
