# EasyMake / XDOS 文件格式

（[FORMAT.md](FORMAT.md) 的中文版。）

本文根据 `XDOS.CMD`（步步高 004 号盘 V2.0；9118 字节，装入地址 `$C300`，入口 `JMP $D1A9`）、
`INSTALL.CMD` 中的音乐驱动程序以及它们调用的步步高 BIOS 功能整理而成。已在 MesenCE 中核对：
`.GRA` 的解码和精灵块的显示与原机逐像素一致，`verify` 能重建 004 号盘的全部文件。

## 运行环境

`AUTOEXEC.BAT`：`bbgcdos/z4`、`install`、`mouse`、`xdos`。XDOS 需要中文系统 BBGCDOS（否则显示
`Not found BBGCDOS!`），还需要 `INSTALL.CMD` 复制到 `$44C1-$4C25` 的音乐驱动程序（`$4CFF=$FF`
表示已装入）。文件名在 XDOS 中是固定的：脚本为 `sdos.dsp`，资源包为 `sdos.res`，直到某个
`resource=` 属性指定另一个资源包。DSP 装入从 `$D0` 开始的 DRAM 页，RES 装入 DSP 结束之后的那一页；
XDOS 会把这个页号加到每个目录项的页号字节上。鼠标指针和按键来自鼠标驱动程序（`$5FF2` 为 x，
`$5FF3` 为 y，`$5FFC` 的第 0 位为按键）。

## .DSP 脚本

GBK 文本，行尾为 CR LF。以 `<` 开头的行是标签，其他行是当前文本框中的文字。属性写成
`名字=值`，用空格或逗号隔开，字符串加 `"`。标签表在 `$E512`（每项 16 字节：14 字节名字加处理
程序地址）；不认识的标签会被跳过。

| 标签 | 属性 | 作用 |
|---|---|---|
| `desktop` | `resource` `background` `backsound` `name` | 新的一屏：隐藏精灵，如果给了资源包就装入它，画出 `.GRA`（BIOS `$42`），开始播放音乐；`name` 是标号 |
| `img` | `src` `left` `top` | 画一个图像对象（精灵以像素为单位；字符块类型以字符格为单位） |
| `animate` | `src` `time` `count` | 播放动画，每帧 `time` 个节拍。没有 `count` 时播放一遍，脚本等它结束；有 `count` 时在后台运行——但只在 XDOS 等待写满的文本框时才动，在 `<menu>…</menu>` 中不动 |
| `static` | `left` `top` `caption` | 在第几列/第几行（32 × 15 个 8 × 16 的字符格）通过 BBGCDOS 显示一行字（光标功能 `$1C`）；第 c 列实际出现在第 (c + 1) × 8 点，字符块图片、精灵和鼠标指针也一样，都比不动的 `.GRA` 偏右 8 点 |
| `speak` | `src` `word` | 说语音资源中的第 `word` 句 |
| `wait` | `time` / `key` / `str` `line` `col` | 延时；等待按键或鼠标点击（`key=0`）；或者检查输入的 `str`（输错时显示 `错误！请重新输入！`） |
| `menu` … `/menu` | | 收集其中的 `menuitem`，然后等待点击 |
| `menuitem` | `left` `top` `right` `bottom` `href` `act` | 以像素为单位的可点击矩形；`act` 为鼠标移上去时的效果 |
| `go` | `href` | 跳到带有该 `name=` 的标签（从脚本开头查找） |
| `textbox` | `left` `top` `right` `bottom` | 以字符格为单位的文本区；后面的文字行写在里面 |
| `page` / `/textbox` | | 换页 / 文字结束 |
| `/desktop` | `name` | 退出 XDOS |
| `answer` `easy` | `result`、`right` | 004 号盘的测验画面：使用 004 号盘自己的 SDOS.RES 中固定的页号和地址——别的节目不能用 |

属性一览：src name background backsound left top right bottom href caption time word count
resource key str line col result act。

文字用背景调色板的第 13 号颜色画在第 12 号颜色上；写字时，字所在的 16 × 16 属性块会被换成第 3
组子调色板。

004 号盘的脚本中有几个字节不是合法的 GBK（步步高字库中额外的符号）；本工具把它们保存为 `{#XX}`。

## .RES 资源包

- 100 个目录项 × 16 字节 = `$640`：12 字节名字（不足补 0）、`0`、地址低字节、地址高字节
  （`$8000-$BFFF`）、页号（从文件开头算起，以 16 KB 为单位）。未用的项为 `$FF`。
- 资源不会跨越 16 KB 的页；空闲处为 `$FF`。
- 资源内部的指针都是该资源所在页中的 CPU 地址，所以互相指向的对象必须在同一页，并且要一起
  移动。不同资源可以共用对象（一个动画可以用另一个资源的帧）。
- 原来的制作工具留下了空洞和旧数据（没有被引用的旧对象、含有旧项的语句表）。重建时保持每个对象
  的位置不变，所以凡是有对象的地方，结果都和原来一模一样。

## 对象

**图像对象**——`类型、数量、数据`（XDOS `$DBB5`）：

| 类型 | 数据 | 由谁画 |
|---|---|---|
| 0 | `数量` 个 GBK 文字字节 | BIOS `$32`，画在光标处；模式 ≠ 0 时前景背景色互换 |
| 1 | `数量` × （`x, y, 属性, ?` + 32 字节的 8 × 16 块）——背景字符块，画在字符格 `(left + x/8, top + y/16)` | BIOS `$36` |
| 2 | 一张 GR 图片（和 `.GRA` 相同） | BIOS `$42` |
| 3 | `数量` × （`dx, dy, 属性（调色板）, 精灵号` + 32 字节的 8 × 16 块） | BIOS `$38`——BIOS 把精灵显示在 x + 8 处 |
| 4 | `数量` × （`列, 行, 序号, 前景色, 背景色, 字符低字节, 字符高字节`）——彩色字符 | BIOS `$2F` |

一个“块”是两个 NES 2bpp 图块，先上后下。`img` 资源在目录指针前面有 16 字节的调色板（类型
0/3/4 为精灵调色板，类型 1 为背景调色板）。

**动画**：数量（14 位；第 1 字节的第 7 位 = 同时装入背景调色板），然后是 数量 × 8 字节的帧
`x, y, 图像指针, x原点, y原点, 模式, 种类`。画在“槽位置 + x − x原点”处（`animate` 的槽位置为
0）；种类 0 用 `$DBB5` 画，种类 1 用 `$DD8E` 画；模式 0 为正常，1/6/7 为变换，`$10` 为擦除。
`animate` 资源是 16 字节的精灵调色板后面跟着动画。共有 8 个动画槽。

**鼠标效果**（act），25 字节：标志（第 0 位音乐，第 1 位语音，第 2 位动画）、音乐头（4）、语音
指针（2）、动画指针（2）、精灵调色板（16）。鼠标进入菜单项时播放（`$C6DD`）；鼠标离开一个带效果的
菜单项时，XDOS 调用 `$CC5B`，对 58 号到 0 号精灵逐个调用 BIOS `$38` 把它们隐藏——不只是效果用过
的精灵，所以页面上的精灵图片也会消失。

**语音**：一个语句指针表，后面是各个语句。一句 = 大端序的长度、`$D6`，然后是这么多字节的、给步步高
语音芯片用的 LPC-10 数据（MesenCE 的 `BbkLpcAudio`，“D6”表；按位读取，低位在先；能量为 15 时
结束）。由 BIOS `$5809`（X=`$11`）播放，它从 `$D6` 开始发送 `长度` 个字节——所以存储的最后一个
字节永远到不了芯片（步步高自己的语句也是这样）；编码器会多补一个字节。

鼠标效果中的音乐和语音：程序中有这两个分支（`$C709`、`$C76C`），但读错了自己的字段——音乐分支
压入三个字节，而驱动程序的调用要四个；语音分支把两个指针字节都装进了 X——所以只有鼠标效果的
动画能用。

**音乐**（给 INSTALL 驱动程序用）：歌曲表指针、声部表指针。歌曲 = `声部数−1, 第一个声部`。声部项
= `槽, 标志（APU 声道）, 数据指针`。声部数据 = 4 字节的音色头（`速度, 占空比, 包络, 滑音`），然后
是 2 字节的事件，以 `$FF` 结束。音符：高 4 位为八度（0 = C2），低 4 位为半音（≥ 12 为休止），后面
是长度。`$A0-$AF` 为音量/滑音/占空比/颤音/分段/速度，`$Bn t` 为循环到第 t 个事件（n = 0：跳到 `$FD`
标记），`$Cn` 为衰减，`$Dn/$En` 为音量渐变，`$FD` 为标记。循环目标是事件序号，所以声部数据移动后
不需要修改。

驱动程序每帧运行一次（50 Hz）。一个声部槽（`$00 $15 $2A $3F`，以及 004 号盘用的
`$54 $69 $7E $93`）有一个速度累加器：开始时为 R = 速度字节高低 4 位互换后加 `$0F`；每帧减去
`$10`，减到负数时就是一个节拍（所以每帧 16 / (R + 1) 个节拍）。事件序号从声部数据开头算起，4 字节
的音色头算作第 0 和第 1 个事件。事件：

| 事件 | 含义 |
|---|---|
| 音符 `on, len` | `o` 为八度（0 = C2），`n` 为半音 0-11，持续 `len` 个节拍；`n` 为 12-15 是休止。在噪声声道上，小于 `$10` 的字节是噪声周期，`$10` 及以上是休止 |
| `$A0 v` | 音量/包络位（占空比不变） |
| `$A1 v` | 滑音 |
| `$A2 d` | 占空比 0-3（三角波声道：线性计数器） |
| `$A3 v` | 颤音：第 4-6 位为形状，低 4 位为延迟（× 2 个节拍）；第 7 位 = 关闭 |
| `$A4 -` | 关闭颤音 |
| `$AD n` | 新的一段：数据从这里重新开始；n = 0：后面跟着一个音色头 |
| `$AE v` | 速度重装值的第 7 位 |
| `$AF t` | 速度 |
| `$Bn t` | n = 0：跳到第 t 个事件（t = 0：`$FD` 标记）。n > 0：循环，往回跳 n 次，所以这一段播放 n + 1 遍（t = 0 和 t > 0 各有自己的计数器） |
| `$Cn l` | 从每个音符开始，在 l 帧内按第 n 种形状（1-9）衰减；只在固定音量时有效（包络的第 4 位） |
| `$Dn p` / `$En p` | 音量升高 / 降低 n 级，每 p 个节拍一级 |
| `$FD -` | 循环标记 |
| `$FF` | 声部结束（一个字节） |

**音乐文本**（`.mus`，`extract` 写出、`build` 读入）：每行一项，`;` 后面是注释。

```
@label:                 定义一个标号
header @songs @tracks   两个表的指针
song 3 0                一个歌曲项
track $54 $00 @t0       一个声部项
inst 31 02 1D 00        一个音色头（十六进制）
C-4 10  / C#4 10        一个音符（音乐上的八度 2-11，所以字节 $29 是 A-4，440 Hz）和它的长度（节拍数，十六进制）
rest $3C 10             一个休止，写出存储的字节
ev A3 22                其他事件（十六进制的操作码和参数）
end                     $FF
db 12 34 ...            原始字节（十六进制）
```

## .GRA

`"GR"`、0、0、宽度（LE16）、高度（LE16）、8 个 0；16 字节背景调色板；`(w/32)·⌈h/32⌉` 字节的
属性表（NES 排列方式）；`w/8 × h/8` 个 NES 2bpp 图块，按行排列。256 × 240 的图片为 15456 字节。
004 号盘的图片中第 0/4/8/12 号颜色为黑色（`$0D`），第 13 号为白色，用来写字。
