# EasyMake 使用指南

EasyMake 是步步高学习机 **XDOS** 超文本播放器的制作工具。XDOS 是步步高 004 号盘 V2.0（及其
98 型版本）上的播放程序：它读取一个脚本文件（`.DSP`）、一个资源包（`.RES`）和若干张全屏图片
（`.GRA`），显示画面、文字、动画，播放音乐和语音，并用鼠标点选菜单。

步步高当年的制作工具 EasyMake（目录第 281 号盘）已经失传。本工具根据 XDOS 程序本身重新做出了
它的功能：可以把现有的盘拆开成可编辑的文件，也可以从零开始制作新的盘，最后写成能在学习机
（或 MesenCE 模拟器）上直接运行的软盘镜像。

文件格式的技术细节见 [格式说明.md](格式说明.md)（英文版：[FORMAT.md](FORMAT.md)）。

---

## 一、准备工作

本工具就是 **`EasyMake.exe`**：一个 .NET 程序，**不需要安装任何其他东西**，双击即可运行。
它由本文件夹里的源代码生成：安装 .NET 10 SDK 后，在本文件夹里运行

```
dotnet publish -c Release -r win-x64
```

得到 `bin/Release/net10.0/win-x64/publish/EasyMake.exe`（约 23 MB，单个文件，可以复制到任何地方使用）。

还需要准备一张**模板盘**：一张已经装有 BBGDOS、中文系统 BBGCDOS、`INSTALL.CMD`（音乐驱动）、
`MOUSE.CMD`（鼠标驱动）、`XDOS.CMD` 和启动它们的 `AUTOEXEC.BAT` 的软盘镜像。
**004 号盘 V2.0 的镜像就可以直接当模板用**。制作时工具会先删掉模板盘上原有的节目文件，
再写入你的新节目，模板文件本身不会被修改。

## 二、图形界面（推荐）

**双击 `EasyMake.exe`** 就会打开编辑器。它会自动打开上次的项目。

### 第一次使用：设置路径

菜单“设置 → 路径设置”，选择三个文件（以后会自动记住）：

| 项目 | 说明 |
|---|---|
| MesenCE 程序 | `Mesen.exe` |
| BBK 1.0 BIOS | BIOS 文件，`.nes` 或 `.zip` 都可以 |
| 模板盘 | 带 XDOS 的启动盘，如 004 号盘 V2.0 的镜像 |

### 窗口布局

- **左边**是项目：脚本、背景、资源包里的各个资源。下面有“添加资源…”“添加背景…”按钮。
- **右边**是所选内容的编辑区。
- **最下面**是信息栏，显示制作过程和出错信息。

### 编辑脚本

点左边的“脚本”。左半边是脚本文字（标签显示为蓝色），右半边是**预览**：显示光标所在那一页在学习机
上的样子——背景、图片、文本框、文字，菜单项的可点击范围用紫色虚线框标出。

- 鼠标在预览图上移动时，下面会显示**像素坐标**和**字符格坐标**，写 `static`、`textbox`、
  `menuitem` 时直接照着填。
- 在预览图上**拖出一个矩形**，就会把对应的 `<menuitem left=…,top=…,right=…,bottom=…,href="">`
  复制到剪贴板；点“插入菜单项”则直接插入到光标处，再填上 `href`。
- 改动脚本后预览会自动刷新；按 Ctrl+S 保存（切换到别的项目时也会自动保存）。

### 编辑资源

点左边的某个资源，右边会出现对应的表单：

| 类型 | 能做什么 |
|---|---|
| 精灵图片 | 更换图片、设置起始精灵号、是否用单独调色板，预览转换后的效果 |
| 字符块图片 | 更换图片、选择使用哪张背景的颜色，预览效果 |
| 动画 / 鼠标效果 | 帧列表：选中一帧可修改 x、y、图片、原点，点“更新”；可以添加、删除、上移、下移帧，点“播放”预览 |
| 语音 | 添加录音（WAV），选中一句点“试听”——听到的就是学习机语音芯片会说出来的声音 |
| 音乐 | 直接编辑音乐文本，“检查”格式是否正确，“试听”听到的就是学习机播放的效果（按学习机的音乐驱动程序逐帧演奏） |

“添加资源…”时选择类型、起名字、选文件即可。从原盘拆出的精确数据只能预览，修改请直接编辑文件
（点“打开所在文件夹”）。

### 生成和运行

- **生成软盘…**：选择保存位置，生成 `.img` 软盘镜像。
- **在 MesenCE 中运行**（F5）：自动生成软盘并用 MesenCE 打开，可以马上看到效果。如果之前用
  “生成软盘…”保存过，就重新生成**那个文件**并打开它（BIOS 要是放在 MesenCE 文件夹里的 `.nes`
  文件，MesenCE 用它启动软盘）；否则用临时文件夹里的副本（`%TEMP%\easymake_run`）。

菜单“设置 → 语言”可以在中文和英文之间切换。

**未使用的资源**在左边显示为灰色并标“（未使用）”。XDOS 同一时间只装入一个资源包，编辑器会从第一页
（装入 SDOS.RES）开始，沿着脚本的页面和跳转算出每一页用的是哪个资源包，再统计各页用到的资源（以及
这些资源引用的图片等）。语音资源会列出每句的 `word=` 编号和说这句的页面；表中指向旧数据的项也会
标出来。脚本里有 `<answer>`/`<easy>` 时，它们按固定地址读取资源包，标为“未使用”的资源仍可能被
用到（信息栏会提示）。双击左边的音乐、语音、动画可以直接播放。

## 三、命令一览（命令行）

不用图形界面时，也可以在命令行里做所有事情。在 `EasyMake.exe` 所在的文件夹里打开命令行窗口
（或者写出 `EasyMake.exe` 的完整路径）：

| 命令 | 作用 |
|---|---|
| `EasyMake new <项目文件夹>` | 生成一个示范项目，可以在它的基础上修改 |
| `EasyMake extract <盘镜像> <项目文件夹>` | 把现有的盘拆开成可编辑的项目 |
| `EasyMake build <项目文件夹> <模板盘> <输出盘> [--repack]` | 把项目做成可启动的软盘镜像 |
| `EasyMake verify <盘镜像>` | 拆开再重建，逐字节检查是否一致（检验工具用） |
| `EasyMake speech <录音.wav> <输出.lpc>` | 把一段录音编码成学习机的语音格式，并输出一个试听用的 `.preview.wav` |

`--repack` 表示把资源包完全重新排列（一般不需要，修改了资源大小时工具会自动重排）。

## 四、五分钟上手（命令行）

```
EasyMake new 我的节目
EasyMake build 我的节目 004.img 我的节目.img
```

（`004.img` 代表你的 004 号盘 V2.0 镜像，请换成实际的文件名；文件名有空格时要加双引号。）

然后在 MesenCE 里用 **BBK 1.0 BIOS** 启动，插入 `我的节目.img`。系统启动后会自动运行
XDOS，出现示范节目：一个蓝天草地的背景、一个机器人、一块招牌、一段音乐、两页文字和两个按钮。
把鼠标移到“下一页”上会出现闪光，点击后进入第二页，机器人会招手。

接下来就是修改 `我的节目` 文件夹里的文件，再重新执行 `build`。

## 五、项目文件夹里有什么

```
我的节目/
  project.json            节目由哪些文件组成
  script.txt              脚本（UTF-8 文本，制作时自动转成 GBK）
  backgrounds/sky.png     背景图片，256×240
  res/sdos/objects.json   资源清单
  res/sdos/robot.png      资源用到的图片、音乐、录音等
  res/sdos/tune.mus
  ...
```

`project.json` 的内容：

```json
{
 "script": "script.txt",
 "res": {"SDOS.RES": "res/sdos"},
 "backgrounds": {"SKY.GRA": "backgrounds/sky"}
}
```

- `res`：资源包。第一个必须叫 `SDOS.RES`（XDOS 固定先读这个名字）。可以有多个资源包，脚本里用
  `resource="xxx.res"` 切换。
- `backgrounds`：背景图片。左边是盘上的文件名（脚本里 `background=` 用的名字），右边是项目里的
  图片（不带 `.png`）。

文件名都要符合 DOS 的 8.3 规则（主名最多 8 个字符，扩展名最多 3 个），资源名最多 12 个字符，
只能用英文字母和数字。

## 六、写脚本（script.txt）

脚本是普通文本。以 `<` 开头的行是**标签**，其他行是要显示在文本框里的**文字**。属性写成
`名字=值`，用逗号或空格隔开，文字值要加双引号。

### 坐标

| 用在哪里 | 单位 |
|---|---|
| `static`、`textbox` | **字符格**：一格 8×16 点，全屏 32 列 × 15 行（列 0–31，行 0–14） |
| `menuitem` | **像素**：全屏 256×240 |
| `img`（精灵图片） | 像素 |
| `img`（字符块图片） | 字符格 |

**注意：在学习机屏幕上，XDOS 放的所有东西都会往右偏 8 点**——文字和字符块图片（第 c 列实际从
第 (c+1)×8 点开始）、精灵、鼠标指针（所以菜单项的范围也一样），只有 `.GRA` 背景不偏。在背景上
画按钮框、文字底框时要按文字实际出现的位置来画。编辑器的预览已经按这个规律显示，鼠标在预览上
显示的坐标是脚本里要写的坐标。

### 标签一览

| 标签 | 属性 | 说明 |
|---|---|---|
| `<desktop ...>` | `background` `backsound` `resource` `name` | 开始一个新画面：清除所有精灵，画背景图，开始播放背景音乐。`name` 是这一页的名字，供跳转使用 |
| `<img ...>` | `src` `left` `top` | 显示一张图片 |
| `<animate ...>` | `src` `time` `count` | 播放动画。`time` 越大越慢（每帧约 `time`/30 秒） |
| `<static ...>` | `left` `top` `caption` | 在指定位置写一行字 |
| `<speak ...>` | `src` `word` | 说出语音资源里的第 `word` 句（从 0 开始数） |
| `<textbox ...>` | `left` `top` `right` `bottom` | 文本框；其后的文字行显示在框里 |
| `<page>` | | 文本框内分页 |
| `<menu>` … `</menu>` | | 中间放若干 `menuitem`，然后等待用户点击 |
| `<menuitem ...>` | `left` `top` `right` `bottom` `href` `act` | 一个可点击的矩形区域；点击后跳到 `href` 指定名字的页；`act` 是鼠标移上去时的效果 |
| `<go ...>` | `href` | 直接跳到某一页 |
| `<wait ...>` | `time` / `key=0` / `str` `line` `col` | 等待一段时间；或等待按键/点击；或让用户输入 `str` 指定的文字（输错会提示“错误！请重新输入！”） |
| `</desktop name="xxx">` | | 退出 XDOS（菜单里 `href="xxx"` 跳到这里即可退出） |

`answer`、`easy` 两个标签是 004 号盘自带的测验画面，只能配合 004 原盘的资源使用，新节目里
不要用。

### 示范脚本

```
<desktop resource="sdos.res",background="sky.gra",backsound="tune",name="main">
<static left=8,top=0,caption=" 欢迎使用 EasyMake ">
<speak src="voice",word=0>
<textbox left=2,top=2,right=29,bottom=5>
这是第一页。
请点击下面的按钮。
<static left=22,top=12,caption="下一页">
<static left=22,top=13,caption=" 退出 ">
<menu>
<menuitem left=168,top=192,right=224,bottom=208,href="page2",act="sparkle">
<menuitem left=168,top=208,right=224,bottom=224,href="bye">
</menu>
<desktop background="sky.gra",name="page2">
<textbox left=2,top=2,right=29,bottom=5>
这是第二页。
<animate time=12,src="wave">
<menu>
<menuitem left=168,top=192,right=224,bottom=208,href="main">
</menu>
</desktop name="bye">
```

按钮本身是背景图上画出来的，`static` 只负责写按钮上的字，`menuitem` 负责可点击的范围——三者
的位置要对齐（字符格 × 8 = 像素横坐标，行 × 16 = 像素纵坐标）。背景上的按钮框要画在往右偏 8 点
的位置：上面的按钮字在第 22 列，屏幕上实际从第 184 点开始，菜单项 168–224 在屏幕上是 176–232。

## 七、资源清单（objects.json）

每个资源有一个名字（脚本里 `src=`、`backsound=`、`act=` 用的就是这个名字）和一种类型
`kind`。最简单的写法：

```json
{"objects": {
  "robot":   {"kind": "img", "source": "robot.png", "first_sprite": 0},
  "sign":    {"kind": "img", "source": "sign.png", "glyphs": true, "palette_from": "sky"},
  "wave":    {"kind": "animate", "first_sprite": 20,
              "frames": [[24, 150, "robot_up.png", 0, 0, 0, 0],
                         [24, 150, "robot.png",    0, 0, 0, 0]]},
  "sparkle": {"kind": "act", "first_sprite": 40,
              "frames": [[0, 0, "star_small.png", 8, 8, 0, 0],
                         [0, 0, "star_big.png",   8, 8, 0, 0]]},
  "tune":    {"kind": "music"},
  "voice":   {"kind": "speak", "phrases": ["hello.wav", "bye.wav"]}
}}
```

### 1. 精灵图片 `img`

`source` 指定一张普通图片（PNG，最大 256×256）。工具自动把它切成 8×16 的精灵块并换成学习机的
颜色。透明部分：图片带透明通道就按透明通道；没有的话，**左上角那个点的颜色**被当作透明色。

- 学习机最多 64 个精灵，**一条横线上最多显示 8 个**，所以太宽的图会闪烁或缺块。
- 同时出现在画面上的几张图，`first_sprite`（起始精灵编号）要错开，否则会互相覆盖。
  第 61 号精灵是鼠标指针，不要占用。鼠标指针用精灵调色板的第 4 组颜色，所以转换出来的精灵
  图片只用前 3 组，第 4 组固定为指针的颜色（与 004 号盘第一页相同）。

### 2. 字符块图片 `img` + `"glyphs": true`

图片画成背景字符块，没有精灵数量的限制，适合比较大的图。

- 必须用 `palette_from` 指定它所在页面的背景（如 `"sky"`），因为字符块图片会用自己的调色板
  覆盖整个画面的背景调色板，只能用那张背景已有的颜色。
- 字符块**不透明**：图里的空白处请画成背景的颜色，不要留黑色（全黑的格子会被自动省略）。
- 在脚本里 `left` 请用**偶数列**。

### 3. 动画 `animate`

`frames` 里每一帧是 `[x, y, 图片, x原点, y原点, 模式, 种类]`：图片画在 (x − x原点, y − y原点)，
模式、种类一般都写 0。帧图片可以是 PNG 文件名，所有帧自动使用同样的精灵块，前后帧不会残留。

- **不写 `count`**：动画播放一遍，脚本等它播完再继续——推荐这样用。动画结束后如果希望人物
  留在画面上，在后面再放一个 `<img>`。
- 写了 `count` 的动画只在“文本框写满、等待翻页”时才会动；在 `<menu>…</menu>` 等待点击时
  不会动。这是 XDOS 本身的行为。

### 4. 鼠标移上去的效果 `act`

写法和动画一样，位置是**相对鼠标指针**的。在 `menuitem` 里用 `act="名字"`。

- 效果播放完之前 XDOS 不理会鼠标点击，所以帧数要少（两三帧就好）。
- 鼠标**离开**带 `act` 的菜单项时，XDOS 会把 0–58 号精灵全部隐藏（只留下鼠标指针），不只是效果
  自己的精灵。所以菜单里用了 `act` 的页面上，精灵图片和动画停下后的最后一帧都会消失。这种页面上的
  图片请用字符块图片（`"glyphs": true`）或直接画进背景，精灵图片放到别的页面。生成软盘和打开项目时，
  工具会提示有这种问题的页面。
- XDOS 里“鼠标移上去播放音乐/语音”的功能本身有错误，用不了，所以只提供动画。

### 5. 精灵调色板是共用的

学习机只有一套精灵调色板，每次显示图片、动画或效果都会换上它自己的调色板。所以同一个资源包里
所有转换出来的精灵图片**自动共用一套调色板**（4 组 × 3 种颜色），由工具从全部图片中选出。
颜色太多时会被合并成相近的颜色。某个资源需要单独的调色板时，加 `"own_palette": true`
（但它出现时其他精灵会变色）。

### 6. 语音 `speak`

`phrases` 列出若干句，脚本里 `word=0` 是第一句，`word=1` 是第二句……

- `.wav` 录音在制作时自动编码（任意采样率，单声道或立体声都可以）。录音要清晰、没有背景噪音、
  音量适中。
- `.lpc` 是已经编码好的语音（从现有的盘拆出来的就是这种，旁边还有 `.wav` 试听文件；文件名就是
  `word=` 的号码，例如 `word0/18.lpc` 是 `word=18`）。
- 先用 `EasyMake speech 录音.wav 测试.lpc` 编码一句（或在编辑器里“工具 → 语音编码试听…”），听听 `测试.preview.wav` 的效果。
  学习机的语音芯片音质有限，大约每秒 170 字节。

### 7. 音乐 `music`

音乐写在 `<名字>.mus` 文本文件里，例如 `tune.mus`：

```
header @songs @tracks
@songs:
song 1 0              ; 一首曲子：2 个声部（写声部数减 1），从第 0 个声部开始
@melody:
inst 31 02 1D 00      ; 音色：速度、占空比、音量包络、滑音（十六进制）
ev FD FE              ; 循环起点
C-4 10                ; 音符 C4，长度 10（十六进制）
G-4 10
A-4 20
ev B0 00              ; 跳回循环起点
end
@bass:
inst 31 00 1C 00
ev FD FE
C-3 20
ev B0 00
end
@tracks:
track $54 $00 @melody ; 第 1 声部：方波 1
track $7E $02 @bass   ; 第 2 声部：三角波
```

- 音符写成 `C-4`、`C#4`、`D-4` … `B-4`，数字是八度（A-4 = 440 Hz），后面是长度（十六进制，
  `10` 是一拍）。休止符写 `rest $0C 10`。
- `track` 的第二个数是声道：`$00` 方波 1、`$01` 方波 2、`$02` 三角波、`$03` 噪声；第一个数用
  `$54`、`$69`、`$7E`、`$93` 中的一个。
- 每页的 `backsound="tune"` 开始播放；没有写 `backsound` 的页面音乐会停止。
- 全部指令（颤音、音量衰减、循环次数等）见 [格式说明.md](格式说明.md) 的“音乐”部分。

## 八、背景图片

背景是 256×240 的普通图片，放在 `backgrounds/` 里。工具会自动换成学习机的颜色：全图共 4 组
调色板，每组 3 种颜色加黑色，每 16×16 点的方块只能用其中一组。

- **文字总是白字黑底**。所以标题栏、文本框、按钮的位置请在背景图上画成黑色。
- 写字时，字附近 16×16 的方块会被换成第 4 组调色板，工具已经尽量让这些方块颜色不变。
- 颜色简单、色块大的图片效果最好；照片类图片会变得很粗糙。

## 九、修改现有的盘

```
EasyMake extract 004.img 004项目
```

拆出来的项目是“精确”的：

- 图片是索引色 PNG（每个点的编号 = 调色板组 × 4 + 颜色），调色板和精灵块的位置记录在 JSON 里。
  请用能**保留索引色**的画图软件修改像素；要改颜色，请改 JSON 里的 `palette`。
- 音乐拆成 `.mus` 文本，语音拆成 `.lpc` 加 `.wav` 试听。
- 每个资源都记录了原来的位置；只要大小没变，重建出来和原盘一模一样。

改完后用 `build` 写回（模板盘可以就用原盘）。

## 十、在 MesenCE 里试运行

1. 用 **BBK 1.0** BIOS 启动 MesenCE。
2. 插入做好的 `.img` 软盘镜像，系统会自动启动 XDOS 进入节目。
3. 用鼠标移动指针、点击按钮。

## 十一、常见问题

| 现象 | 原因和解决办法 |
|---|---|
| `disk full` | 盘满了。减少背景图片数量（每张 15 KB）或缩小资源 |
| `needs N sprites; the machine has 64` | 精灵图片太大，改用字符块图片（`"glyphs": true`）或缩小 |
| 精灵颜色不对 | 同一画面的精灵共用一套调色板，颜色总数太多会被合并；减少颜色 |
| 动画不动 | 写了 `count` 的动画在菜单等待时不会动，去掉 `count` |
| 鼠标移上去后点击没反应 | 移上去的效果（`act`）还在播放，减少它的帧数 |
| 鼠标离开按钮后图片不见了 | 离开带 `act` 的菜单项时 XDOS 隐藏所有精灵；这一页的图片改用字符块图片，或去掉 `act` |
| 文字周围的背景变色 | 写字会改变附近方块的调色板；把文字放在黑色区域 |
| 字符块图片周围有黑块 | 字符块不透明，图里的空白处要画成背景色 |
| 语音听不清 | 用更清晰、音量适中的录音；先用 `speech` 命令试听 |
| `not a FAT12 floppy image` | 镜像不是普通软盘镜像（例如 `.imz` 压缩镜像），请先解压 |
